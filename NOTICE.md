# Attribution

This project is an Android and self-hosted adaptation inspired by
[`bella-and-c/sleepy-dog-lock`](https://github.com/bella-and-c/sleepy-dog-lock),
which is distributed under the MIT License.

The adaptation adds an Android accessibility-based guard, a zero-dependency
self-hosted Node.js server, dual MCP authentication for ChatGPT/Codex, and an
explicit wake/deactivation tool.
