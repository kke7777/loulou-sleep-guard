再不去睡露露就要生气啦 · 服务器端 v1.0.1

服务器会直接从 GitHub 下载本仓库，不需要用安卓手机上传压缩包。

首次部署：进入本仓库的 server 目录后，填写 HTTPS 地址（没有自有域名时可使用 sslip.io），再依次运行：

  npm run setup
  pm2 start pm2.config.cjs
  pm2 save

setup 会询问 HTTPS 地址，自动生成 .env 和随机密钥；请妥善保存它显示的“手机连接令牌”和“网页授权口令”，不要公开截图。

已经部署过旧版本时，在仓库目录执行：

  git pull --ff-only
  cd server
  pm2 restart pm2.config.cjs --update-env

v1.0.1 新增 /api/device/stream SSE 长连接。Android 前台守卫会通过它即时收到 MCP 激活/解除状态，同时保留定时同步和打开受限应用时的即时服务器确认。Nginx 示例已关闭代理缓冲，适合 SSE。

Nginx 和 HTTPS 证书需要根据实际域名配置。到这一步时，把域名告诉 Codex，它会继续逐步带你完成。
